## 6. HONEST LIMITATIONS (all verifiable)

1. **Two qrel regimes**: v1 IR numbers are weak-supervision proxies ("NOT publication-grade", file header); only v2 is human-adjudicated (single assessor — no inter-annotator agreement).
2. **R@5 denominator**: averaged over 6 rel-bearing queries only; Q5/Q8–Q10 had zero relevant top-10 items (v2 summary `R@5_queries_used`).
3. **Zero-GT labels**: pneumonia, atelectasis, "no finding" excluded from AUC mean (n_images_with_gt = 0, v2 auc_table).
4. **Inverted-AUC reliance**: best_auc takes max(positive, inverted-negative); effusion scores .000 positive but .929 inverted (v2 auc_table) — sign of miscalibrated negation scoring, not skill.
5. **Cross-link coverage 48/100**: only 48 sampled studies matched source reports (crosslink_report.json); insert-vs-final deltas (99→48 RD, 661→321 FN) are MERGE dedup effects.
6. **VLM evaluation scale**: n=20 images, single binary-question slice; token-overlap EM is a crude proxy (not clinical correctness); 11.5 s/img CPU latency.
7. **Graph-Only returns ~5 items** under a k=10 protocol (step17 summary) — depth-starved by design; comparability caveat recorded in metadata truncation rule.
8. **MedGraphRAG avg_items 9.68 < 10**: document-level dedup drops duplicates post-fusion (pipeline Stage behavior observed in run logs).
9. **J8 pilot sha ambiguity**: WORKLOG cited "c500e55a" while the pilot file hashes cad0cc206cafd223… and contains no internal artifact field; resolved going forward by embedding artifact_sha256 in every artifact (step17 metadata note).
10. **openi_chunks supersession**: f59560a3… → b60730ca… after image_ids bugfix; older sha appears in earlier WORKLOG rows.
11. **BiomedCLIP via third-party mirror + local shim patches** (4 transformers-5 compatibility patches inside the model dir) — weights are upstream microsoft BiomedCLIP per README, but provenance chain includes local edits (model-dir README + patched files).
12. **Official CheXzero weights unavailable publicly** — v2 uses BiomedCLIP substitute; comparison to published CheXzero numbers is therefore indirect (vf2 model field).
