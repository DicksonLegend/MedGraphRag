## 8. Format-specific routing

- **PDF, DOCX, PPTX, images → IBM Docling.** GPU on (RTX 3050, 6 GB VRAM). Initialize the model **once**, stream files **sequentially** — never multiprocess GPU workers (will OOM at 6 GB). - **XLSX / XLS → Pandas (`openpyxl`), NOT Docling.** Rows → `structured_data`; a serialized text render → `text.body`. `extraction_tool = pandas_xlsx`.
- **CSV, TSV, Parquet → Pandas** (CPU). `orient='records'`. - **TXT / Markdown → auto-detected encoding** into `text.body`. `extraction_tool = text_parser`.
- **Archives (.zip/.tar/.gz/.tgz) → unpack into a staging dir, then recursively run each inner file through this same dispatcher** (apply SKIP/REVIEW rules to inner files too). - **Large-file safety:** any single file > 2 GB pauses and asks me before processing.

## STEP 2 — THE CRITICAL FIX: Hybrid PDF Parsing Strategy

### Stage 1: PyMuPDF (fast, CPU-only, no GPU)

```
Open PDF with fitz
    → Extract text from each page
    → Check: does the extracted text have meaningful content?

    → YES → Use this text. Done. No GPU needed.
    → NO  → Fall through to Stage 2
```

PyMuPDF handles **80–90% of PDFs** (text-based PDFs, digital PDFs, most guidelines, most research papers) using **zero GPU memory**. It is extremely fast.

### Stage 2: Docling (GPU, only when needed)

Only if PyMuPDF extraction fails or returns near-empty text (scanned PDFs, image-heavy PDFs, complex table layouts):

```
Load Docling models ONCE (lazy loading — only when first needed)
    → Process ONLY the problematic PDF
    → Extract text + tables + figures
    → Immediately after processing:
        torch.cuda.empty_cache()
        gc.collect()
    → Unload Docling models from GPU if no more scanned PDFs remain
```

### Implementation rules for this strategy:

- **PyMuPDF is the DEFAULT parser for all PDFs.** Docling is the FALLBACK.
- Docling models must be **lazy-loaded** — do NOT load them at pipeline startup. Load them only when the first scanned PDF is detected.
- After every Docling-processed file, call `torch.cuda.empty_cache()` and `gc.collect()`.
